# Sello de datos simulados

Dice, en cada lugar donde hay un dato o una imagen, que los datos son simulados.

```html
<span class="co-ficha co-ficha--simulado"><svg class="co-ic">…</svg>Simulated data</span>
<span class="co-sello">Simulated</span>   <!-- dentro de una imagen -->
```

- Tres lugares, siempre los tres: en la franja superior (fijo), dentro de cada imagen y al pie de cada informe, con el texto completo.
- Borde de trazos y gris: informa, no alarma. No usa ningún color de nivel.
- No se puede cerrar ni ocultar.
- El texto completo sale de `PRODUCT.simulatedDataNotice`.

Los valores de los ejemplos son datos simulados: tripulante ficticio C, día de vuelo 118.
