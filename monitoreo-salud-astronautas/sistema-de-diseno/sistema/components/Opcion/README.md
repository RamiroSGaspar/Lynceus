# Opción y entrada

Las respuestas del cuestionario y de las pruebas, y el renglón para escribir una pregunta.

```html
<label class="co-opcion"><input type="radio" name="near"> No change</label>
<input class="co-entrada" type="text" placeholder="…">
```

- Cada opción es una fila entera que se toca, de 52 px de alto o más, con borde fino.
- **La elegida se invierte:** fondo blanco, texto negro. No hay forma de no verla.
- La entrada de texto es un renglón: sólo la línea de abajo, como una lectura.
- Van sobre negro liso, sin campo detrás.
- Las superficies de estímulo de las pruebas (la C de Landolt, la grilla de Amsler) **no son parte de este sistema**: conservan su fondo, su contraste y su tamaño calibrado. El sistema sólo viste lo que las rodea.

Los valores de los ejemplos son datos simulados: tripulante ficticio C, día de vuelo 118.
